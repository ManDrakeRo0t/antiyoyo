# План

### Улучшения в коде

* Каждый юнит будет иметь свой цвет
* Перед ходом будет собираться контекст выполнения для минимизации расходов
* У клеток будет объект графики для настроек видимости и эффектов
* Новый объект игры хранящий чат
* Новый объект игры хранящий состояние отношений 
* Юниты сами дают эффекты на евенты игры, меньше кор логики на которой все завязаны 
* разбить ход на состояние, этапы и понять где что обновляется
* История игры в виде списка изменений
* аутентификация
* разбить код на бины
* меньше статики и утилит, только основные подсчеты

### Новые механики

* предусмотреть больше кастомных настроек для разнообразного геймплея (одна жизнь у таунхолла)
* туман войны 
* союзы (запрет на атаку и трейд ресурсов)
* игра на кол-во шагов или ограничение по времени
* разделение мощности на атакующую добывающую и территориальную 
* игра с постройкой начальной базы и сразу в геймплей
* улучшения в глубину, с потерей добычи 2 лвл фермы == 1.5 обычного
* получения ресурсов за уничтожение заводов
